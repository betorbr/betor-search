- (decision) Paradigma adotado: arquitetura em camadas enxuta (transport HTTP -> aplicação -> contrato de domínio), suficiente para fase 1 e compatível com evolução incremental.
- (version) Versão base verificada na web: Go estável 1.27.1 (go.dev/dl em 2026-09-18).
- (decision) AD-1 fixa superfície HTTP: /health suporta GET e HEAD; demais métodos retornam 405 para prevenir divergência de contrato entre implementações.
- (decision) AD-2 fixa envelope de resposta health: JSON com status UP, components vazio e timestamp ISO 8601, garantindo previsibilidade de integração.
- (decision) AD-3 fixa isolamento operacional: health check não consulta dependências externas para manter disponibilidade e baixa latência na fase 1.
- (decision) AD-4 fixa porta padrão local 8080 e ownership do bootstrap HTTP em cmd/server para evitar duplicidade de inicialização.
